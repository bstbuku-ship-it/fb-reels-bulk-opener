# 多平台批量打开助手

一键批量打开 FB 与 YT 创建页的 Chrome 扩展：点一下就按数量打开多个标签页，右上角切换平台。

## 功能

- **FB / YT 切换**：右上角 FB、YT 两个小按钮切换，FB 蓝色主题，YT 暗红色主题。
- **批量打开**：FB 默认 5 个，YT 默认 3 个，各记各的数量，下次打开还是上次用的数；数量 1–30，可输入可点快捷按钮。
- **FB 真实主页识别**：先探测真实主页编号，识别到就在头部显示头像和编号，点编号可复制。
- **没账号不打开**：FB 拿不到真实编号、YT 拿不到频道编号，就说明这个浏览器上没登录对应账号，这时只留探测页那一个登录页，上传页、创建页一个都不开，只提示先登录。
- **FB 自动打开日程本**：设置里打开后，批量打开前先开日程本。
- **YT 自动打开短视频列表**：设置里打开后，先开频道页拿编号，再跳到该频道的 Shorts 列表。
- **设置干净**：偏好设置只有两项前置任务和更新检查，底部只留版本号。
- **更新检查**：打开时静默检查 GitHub 有没有新版本，有新版时版本号旁边的点变橙色并弹出更新提示；点版本号可以手动再查一次。

## 安装（加载已解压的扩展程序）

1. 在 GitHub Releases 里下载最新版本的 zip，解压到一个文件夹（不要删除这个文件夹，扩展要一直从这里读取）。
2. 打开 Chrome，进入 `chrome://extensions`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择刚才解压出的文件夹（里面有 `manifest.json`）。
4. 点工具栏的扩展图标打开「多平台批量打开助手」。

更新时：有新版时版本号旁边的点变橙色，点「更新」去 Releases 下载新版 zip，解压覆盖旧文件夹，然后在 `chrome://extensions` 里点「重新加载」。仅点「重新加载」不会清空已保存的设置。

## 使用

- 点右上角 FB 或 YT 切换平台，调好数量，点「快速批量打开」。
- FB：会先探测真实主页编号，再批量打开 Reels 创建页；设置里打开「自动打开日程本」会先开日程本。
- YT：直接批量打开上传页；设置里打开「自动打开短视频列表」会先开频道页拿编号，再跳到 Shorts 列表。
- 注意：上传用的是当前登录账号正在用的频道，传错频道的风险在切换频道，不在插件；多频道建议用不同的 Chrome 用户配置。

## 版本说明

- v5.0（2026-11-24）：重大更新，新增 YouTube 板块。FB 与 YT 都能批量打开，右上角切换，各记各的数量；FB 先探测真实主页编号并显示头像和编号；YT 批量打开上传页，设置里可自动打开短视频列表；没登录账号时只留一个登录页，不打开别的页；顶栏左边的标志和标题上下居中。
- 安全审计：无第三方依赖、无远程代码；仅有的对外请求是：打开 FB / YT 页面、探测 FB 主页编号、以及检查更新时向 GitHub API 请求公开的最新 Release 信息。不含任何用户数据，没有硬编码的认证 Token。
