# FB Reels 批量开启 · Chrome / Edge Extension

访问 Facebook 官方创建页，自动获取真实专业主页编号，一键批量打开 Reels 创建页。

## 功能特性

* **官方链接自动回填真实编号**：直接打开 Facebook 官方的 Reels 创建页（`business.facebook.com/latest/reels_composer/`），由 Facebook 自身把当前登录专业主页的真实公共主页编号（`asset_id`）回填到网址中，插件监听这个变化拿到编号——不再依赖解析页面 DOM/脚本猜测，稳定性大幅提升
* **探测优先，批量紧随**：点击开始后先打开 1 个探测页确认真实编号（最多等待 8 秒），随后用真实编号批量打开其余创建页；若探测超时，自动降级为直接批量打开裸链接，Facebook 会各自完成回填，不阻塞使用
* **自动预开日程本**：确认真实编号后，探测页可自动切换为对应专业主页的内容日历（日程本），无需额外操作
* **弹窗预览卡片**：若已打开的标签页里能直接读到真实公共主页编号（URL 参数解析，100% 准确），弹窗会显示真实头像和编号，并支持一键复制；识别不到就不显示，不做不准确的猜测
* **偏好设置面板**：右上角齿轮按钮进入设置，所有配置带记忆，下次直接生效

  * 打开数量自动记住上次使用值（无需单独设置）
  * 自动打开日程本开关
  * 启动时检测更新：始终开启，无需开关
* **灵活数量控制**：支持 1~30 个标签页，提供快捷按钮（3 / 5 / 8 / 10 / 15）
* **版本自动检测**：启动时自动检测 GitHub 最新版本，有新版本时弹出更新提示

## 安装方法

### Chrome

1. 前往 [Releases](https://github.com/bstbuku-ship-it/fb-reels-bulk-opener/releases/latest) 下载最新版 ZIP
2. 解压到本地文件夹
3. 打开 Chrome，地址栏输入 `chrome://extensions/`
4. 右上角开启**开发者模式**
5. 点击**加载已解压的扩展程序**，选择解压后的文件夹
6. 扩展图标出现在工具栏，点击即可使用

### Edge

本插件基于 Manifest V3 编写，与 Edge（Chromium 内核）完全兼容，安装方式相同：

1. 下载并解压 ZIP
2. 打开 Edge，地址栏输入 `edge://extensions/`
3. 左下角开启**开发人员模式**
4. 点击**加载解压缩的扩展**，选择解压后的文件夹

## 使用方法

1. 点击扩展图标打开弹窗
2. 选择要打开的数量
3. 点击**快速批量打开**
4. 插件会先打开 1 个探测页确认当前登录的专业主页真实编号，随后自动批量打开其余创建页（如开启了「自动打开日程本」，探测页会自动切换为日程本）

> 💡 无需提前收藏书签，也无需提前打开 Facebook——点击按钮即会自动完成探测和批量打开。

## 批量打开逻辑

|情况|行为|
|-|-|
|探测到真实编号 + 开启日程本|探测页切换为日程本，另开 N 个带真实编号的创建页|
|探测到真实编号 + 关闭日程本|探测页本身作为第 1 个创建页，另开 N-1 个|
|8 秒内未探测到编号|探测页保留为第 1 个（盲开，仍会自动回填），另开 N-1 个裸链接|

## 权限说明

|权限|用途|
|-|-|
|`tabs`|批量创建新标签页；监听探测页 URL 变化以读取真实编号；扫描已打开标签页 URL 用于弹窗预览|
|`storage`|保存偏好设置（打开数量、日程本开关）|
|`host_permissions`|访问 Facebook Business 页面完成探测与批量打开、访问 Graph API 获取头像、访问 GitHub API 检测版本更新；访问 Graph API 图片响应涉及的 Facebook CDN（`*.fbcdn.net`）|
