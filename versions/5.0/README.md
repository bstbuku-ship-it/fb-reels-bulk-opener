# 多平台批量打开助手 v5.0

名字：多平台批量打开助手，版本 5.0。

改了什么：
- FB 和 YT 都能批量打开，右上角切换，FB 在上面，齿轮在下面。
- FB 默认 5 个，YT 默认 3 个，各记各的。
- FB 保留原来那套：先探测真实编号，识别到就显示头像和编号；设置里 FB 自动打开日程本默认开。
- 没账号不打开：FB 拿不到真实编号、YT 拿不到频道编号，就说明这个浏览器上没登录对应账号，这时只留探测页那一个标签页（那页就是登录页，让用户自己去登录），上传页、创建页一个都不开，只报一句话让先登录，不给用户添乱。
- 顶栏左边的标志和标题上下居中，不再偏上。
- YT 不做头像识别，点之前先确认频道编号，再批量开 youtube.com/upload；设置里 YT 自动打开已排期内容默认开，前置任务按两步法开短视频列表：先开 studio.youtube.com/channel/，等浏览器自动带上频道编号，再跳到 studio.youtube.com/channel/<频道编号>/videos/short，就是频道内容里选了 Shorts 的那页，两步在同一个标签页里接上做。前置任务没开时，探测页只是用来确认账号，拿到编号就关掉。之前用的 studio.youtube.com/videos 打不开，正确地址一定要带频道编号。
- IG 按钮已去掉。
- 设置页没有多余提示，底部只留 v5.0。检测更新保持原样，仍指向原来那个仓库。

安装：
1. 解压这个包，得到一个文件夹。
2. 打开 Chrome，输入 chrome://extensions，打开右上角开发者模式。
3. 点加载已解压的扩展程序，选这个文件夹。

真机验证还没做：请先在 Chrome 里装上，FB 和 YT 各开一次，看数量、切换、头像、日程本和短视频列表页是不是都对。YT 前置任务那页应该直接落在 Shorts 列表上，不是工作室首页。再测一次没登录的情况：退出脸书账号后点 FB，应该只留探测页那一个登录页，一个创建页都不开，只报没检测到脸书账号；退出油管账号后点 YT 也一样，只留一个登录页，一个上传页都不开。
